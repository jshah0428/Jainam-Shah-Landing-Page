PR. 02

PayPark

Note // architecture

Next.js Express FastAPI PrismaDB XRPLedger TomTom API RLUSD

PayPark is a blockchain-integrated parking platform built with Next.js, Express, FastAPI, and PrismaDB, leveraging the XRPLedger (RLUSD) for on-chain parking payments. It integrates TomTom API for real-time parking data, supports automated RLUSD issuance, and enables synchronized wallet and session management. This cuts out credit card fees, allows for flexible parking options (pay by minute rather then by hour), and settles payments much quicker

  • Next.js
  • Express
  • FastAPI
  • PrismaDB
  • XRPLedger
  • TomTom API

PR. 06

WasteFree

Note // architecture

Kivy Python SQLite Mindee OCR

Wastefree helps reduce food waste by tracking pantry items and suggesting ways to use them efficiently. Using receipt data with our receipt scanner, it monitors expiration dates along with unit economics with our virual pantry management feature, and provides popular, tailored meal ideas to minimize waste. Built with Kivy, Python, SQLite, and Mindee’s OCR, it features a receipt scanner, manual item management, expiration alerts, and recipe suggestions. By promoting sustainability and smarter food use, Wastefree benefits both users and the planet.

  • Kivy
  • Python
  • SQLite
  • Mindee’s OCR
